DEPLOYMENT CHECKLIST
====================

BEFORE YOU DEPLOY:
□ Updated all placeholder links (LinkedIn, GitHub, etc.)
□ Added profile photo
□ Added resume PDF
□ Customized About page
□ Added real projects (at least 3)
□ Updated CV with your experience
□ Tested locally (open index.html)

TO DEPLOY:
1. Initialize git:        git init
2. Add files:            git add .
3. Commit:               git commit -m "Initial commit"
4. Create GitHub repo:   (via github.com)
5. Add remote:           git remote add origin [URL]
6. Push:                 git push -u origin main
7. Enable Pages:         Settings → Pages → main branch
8. Wait 2-3 minutes
9. Visit: https://YOUR_USERNAME.github.io/portfolio/

AFTER DEPLOYMENT:
□ Test all links
□ Check mobile responsiveness
□ Verify contact form
□ Share on social media
□ Add to resume/LinkedIn
